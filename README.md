# Quiet Desk Calculator

A small beginner-friendly calculator built for **Task 02 — HTML, CSS & Basic JavaScript**.

## What it demonstrates

- HTML structure and buttons
- CSS layout, responsive design and a custom visual style
- JavaScript variables, functions, conditions and event listeners
- Addition, subtraction, multiplication, division and percentage
- Clear and backspace
- Keyboard support
- Division-by-zero handling


## Run it

No installation is needed.

1. Download or clone this project.
2. Open `index.html` in a browser.
3. Click the buttons and try a calculation.
4. You can also use the keyboard.

## Beginner learning path

### 1. Start with HTML
Open `index.html`.

Find:
- the display: `<div id="display">`
- number buttons: `data-number`
- operator buttons: `data-operator`
- action buttons: `data-action`

### 2. Style it with CSS
Open `style.css`.

Practice changing:
- `--accent`
- `--paper`
- `--ink`
- button sizes
- border radius

### 3. Make it work with JavaScript
Open `script.js`.

The main functions are:
- `inputNumber()`
- `chooseOperator()`
- `calculate()`
- `clearCalculator()`
- `backspace()`

### 4. Test these examples

```text
7 + 8 = 15
20 − 6 = 14
9 × 5 = 45
80 ÷ 4 = 20
50 % = 0.5
```
